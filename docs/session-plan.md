# Session plan

Fill this in before going live and say it out loud as your opening. Choosing the task
while on air is where most dead air comes from.

```text
Date:
Length: 45 / 60 / 90 min (start short, build up)

Goal (one sentence):

Tasks (2-3, each finishable in one block):
  1.
  2.
  3.

Block timer: 25 / 45 min        Break: every block, 5 min

Stuck plan (what I do if the first task stalls past 15 min):
```

Then load it into the HUD:

```sh
npm run session -- reset
npm run session -- goal "..."
npm run session -- task add "..."
npm run session -- timer 45 "Block 1"
```

## Opening (about two minutes)

1. Who you are and what you are building, in one sentence, for anyone who just arrived.
2. The goal and the tasks, read from the HUD.

## At the end of each block

Do a 30-second recap: what worked, what didn't, what's next. It fills the silence
naturally, helps latecomers, and gives you a clean place to take a break.

## Closing

Recap the session, say what the next one is, and stop the stream. Don't trail off.
